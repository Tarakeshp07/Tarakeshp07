### 📌 Project Highlights

🔹 **Sentinel Fusion AI × FinSpark** · *FinSpark Hackathon 2026: Best Idea + 2nd Runner-up (team)*  
Four fraud and security models fused into one threat score: 0.989 ROC-AUC across 498,726 events, ~90ms per incident with SHAP explanations. I built **FinSpark**, the banking platform the models run inside: a fraud gateway on every payment (OTP, analyst hold, freeze) and money held as BigInt paise on a double-entry ledger.  
[FinSpark repo](https://github.com/Tarakeshp07/Finspar-X-Bank-Simulator)

🔹 **Manufacturing ERP** · *Skill Hive Innovations, live at two client sites (private)*  
Multi-tenant ERP for procurement, inventory, production and sales. One codebase, per-tenant modules, Zoho Books sync, Redis + WebSocket stock tracking, tenant-isolated RBAC. Shipped as a Tauri desktop app.

🔹 **HRM & CRM** · *Skill Hive Innovations, in daily use by 20+ users (private)*  
HRM with one domain layer behind a web portal, AI copilot, MCP server (115 tools) and chat apps, fail-closed tenant isolation and 407 test files. CRM with versioned quotations and partial invoicing.

🔹 **Cloud Resource Allocation RL Agent** · *Meta x Scaler AI Hackathon 2026 (team)*  
OpenEnv environment for Kubernetes-style autoscaling, with a DQN agent plus an LLM agent fallback.  
[Repo](https://github.com/Tony-AJ/Cloud_Resource_Allocation_DevOps-AI-Agent) · [Live demo](https://tonyaj5759-cloud-rl-env.hf.space)

🔹 **AssetFlow & People Pay 360** · *Odoo Hackathon: Finalist (team)*  
Asset management ERP with a 7-state lifecycle and double-allocation guard, plus an HR and payroll platform (NestJS, Next.js, PostgreSQL).

🔹 **DEVFORGE**  
Hybrid vector + graph retrieval: ChromaDB embeddings, weighted cosine similarity plus BFS graph scoring, FastAPI and React.
